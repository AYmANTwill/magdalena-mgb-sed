### Step 3 — the six .docx/.pdf files: read, searched, adjudicated

All six were **read in full** (`python-docx` for the five `.docx`, PyMuPDF for the PDF; both already
installed — nothing new added). Plain-text dumps kept in the session scratchpad. Findings and every
unique fragment are written up in **`docs/38_data_acquisition_protocols.md`**, section by section,
each attributed to its source file.

Searched (not assumed) for prior coverage: `docs/08`, `docs/10`, `docs/11`, `docs/12`, `docs/16`,
`docs/19`, `docs/20`, `docs/32`, `docs/35`, `docs/36`, `CLAUDE.md`, `README.md`, `src/*.py`,
`notebooks/*.ipynb`, grepping distinctive strings (`agrologia`, `mapageneraldesuelos`,
`CARACTERÍSTICAS`, `s54a-sgyg`, `a partir de la CM`, `Concentración media diaria`, `684`,
`colombiaenmapas`, `dhime_target_stations`, `OMAR_magdalena_codes`, `1,130,236`, `269,305`, …).

Result per file (detail in `docs/38 §6`):

- **PRECIPITACION.docx** — richest unique content. The precipitation acquisition step is *not*
  documented anywhere: `docs/16 §2` starts the pipeline *after* the download. Extracted: portal
  settings, the **≤2 stations per 0.25° cell / installed-before-2011** curation rule behind the
  684-station target list, the TWILL/Omar priority split, and the `s54a-sgyg` viability rationale.
  The referenced list files live under gitignored `data/raw/` — so the rule was in no versioned file.
- **PRECIPITACION_OMAR.docx** — unique: `http` not `https` for the portal, department-sweep strategy,
  the 11-year-query split rule, the 9-department zip table.
- **SEDIMENTOS.docx** — unique: ~50-station / ~30-year Diario limits, the **1970–1989 second batch**
  rule for pre-1990 records (explains `ssc_santander_1968_2014.csv`), blank-`FechaFin` filter,
  per-department non-basin código counts, the do-not-open-in-Excel rule.
- **IDEAM_Magdalena.docx** — mostly superseded by `docs/11`, which is more detailed *and* carries the
  outcomes. Unique: the original 1980–2018 window and its "~50-year cap" claim (**contradicts**
  `docs/11`), the full-history rationale, the zone-29/Calamar warning.
- **Guia_descarga_suelos_IGAC.docx** — QGIS route superseded by `src/download_igac_soils.py`.
  Unique: the **49 % / ~99 % Fine / 19 % Coarse / 32 % Medium** SoilGrids-vs-IGAC comparison (nowhere
  else as numbers; only qualitatively in notebook 05 and as `figures/igac_vs_soilgrids.png`), the
  `CARACTERÍSTICAS_SUELOS` acceptance check, and the `colombiaenmapas.gov.co` fallback.
- **Explanation_script_MGB_SA_Magdalena.pdf** — read all 8 pages. **No unique knowledge**: every
  distinctive number traces to the tracked `notebooks/06_data_inventory.ipynb` and to `docs/17`,
  `docs/19`, `docs/34`. **But it is an active citation** — `docs/35_qpeak_preregistration.md` quotes
  it twice (the 30 m cell-limit sentence, and "slope feeds the MUSLE LS factor"), and two C3 journals
  cite it as *the only PDF in the repo*. → **KEEP. Not proposed for removal.**

Two contradictions surfaced and are recorded in `docs/38 §7` (DHIME Diario date cap ~30 vs ~50 years;
`docs/10`'s "a partir de la CM" instruction vs the .docx's warning against it — neither was the
variable finally used; the project runs on CM = *Concentración media diaria*). No committed number
was changed. I deliberately did **not** patch `docs/10`: it is outside this agent's remit and the
