# `docs/agents/` — the process archive

**Nothing in this directory is authoritative.** These are *journals*: what an agent was asked to
do, what it tried, in what order, and what it refused to do. They exist so that a decision's
**order** is auditable — chiefly, that a pre-registration was written *before* the numbers it
judges. To look up a fact, use the numbered document that owns it (`docs/00_INDEX.md` names the
owner for every topic).

**This directory IS the archive for process records.** It was left in place rather than moved
under `docs/archive/` for a measured reason: 67 of its files are cited by name from live numbered
documents — 125 citation sites in all, several of them inside **frozen** pre-registrations
(`docs/33`, `35`, `42`, `45`, `46`) that may only be changed through their own amendment slots.
Relocating the directory would break those citations to no navigational benefit. See
`docs/archive/README.md` for the archive policy and the full register.

**Two kinds of file live here.**

- `journal_*.md` — one per agent task. Historical; read for *how* a verdict was reached.
- `PROMPT_*.md` — session hand-off prompts. A prompt is live until the work it describes is done.

**Findings that live only here** are listed in `docs/00_INDEX.md` §6, which flags them as at risk
of being lost and names the document each is expected to be promoted into. That list is the one
thing in this directory a reader should treat as a to-do rather than a record.

**Naming rule, learned the hard way:** parallel agents have overwritten each other's reports in
this project. Every agent gets a **different** journal filename.
